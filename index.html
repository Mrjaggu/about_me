03 · Systems

Selected work

Flagship · Axis Bank · 2023 – present

Call Analytics Intelligence Platform

An enterprise platform that listens to every contact-centre call and turns it into intent, sentiment, compliance flags, a 20-parameter quality score and agent-level performance trends. Around 2,000 call-hours a day, on a model-agnostic stack.

  1. The call An RM helps a customer; the conversation is recorded.
  2. Telecom network The audio travels over PSTN / SIP trunks into the bank.
  3. Bank network Inside the firewall, the recording server captures the call.
  4. Secure storage Recordings land in encrypted storage, ready for analysis.
  5. AI framework Pluggable ASR transcribes, an LLM scores the call on a 20-point rubric, with PII masked throughout.
  6. Business dashboard Scores, compliance flags and trends flow to the business.
  7. Feedback loop The RM sees exactly what to improve on the next call.

Architecture

Model-agnostic by design: a config-driven router puts open-source models (served on vLLM) and managed APIs (OpenAI, Gemini, Bedrock) behind one interface with fallback chains — for ASR and LLMs alike.

Quality

A Cohen's κ inter-rater harness measures model scoring against human auditors on every rubric parameter before changes ship.

Impact

1.2M+ interactions a month for 18,000+ agents; relationship-manager analytics across ~60K calls/day and 10K+ RMs.

Agentic AI · Investor Relations · 2026

IR Question Intelligence Platform

AI agents for the next earnings call. The platform predicts which questions analysts will ask, profiles each analyst's recurring themes across quarters and banks, and grounds every answer in transcripts and disclosures — then turns it all into a call-ready brief. It started as a knowledge-graph prototype; when it overfit to a single quarter, I rebuilt it as an agentic system with the graph as long-term memory and an eval harness to test generalization.

Forecastranks likely questions from disclosures + analyst history
Analystprofiles each analyst's themes and follow-ups
Evidencegrounds answers in transcripts and filings, with citations
Briefassembles call-ready prep material
Shared memory · knowledge graph of analysts, topics and open threads across FY22 → today
Illustrative run · preparing one question

  2. analystAnalyst A · raised asset quality in 3 of the last 4 calls, across 2 banks · follow-up likely
  3. evidencegrounded in last quarter's transcript + investor presentation · 2 citations
  4. briefadded to the call-prep pack with a suggested answer and supporting data points

Evaluation

Held-out quarters as the test set, question-recall scored against what analysts actually asked, and a backtesting loop for every weight change.

Operations

04 · Approach

How I build

Measure first

No model change ships without an eval that agrees with human reviewers. Better means faster inference, higher recall, lower hallucination rate — in numbers.

Own the inference

In a bank, data residency decides the architecture. Self-hosted serving, tuned for the GPUs you actually have, beats a slide about the GPUs you wish you had.

Compliance is a design input

PII masking, access control and audit trails are designed in from day one — which is how you reach production with zero regulatory observations.
